# Security Policy

## Supported Versions

NeoCloud Node has not published its first stable release. Security fixes are
currently made on the default branch and included in the next tagged release.

| Version | Supported |
| --- | --- |
| Default branch | Yes |
| Latest tagged release | Yes |
| Older snapshots and tags | No |

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub private
vulnerability reporting when it is enabled for the repository, or email
`maintainers@aibrix.ai` with:

- the affected version or commit;
- the impact and the conditions required to reproduce it;
- a minimal reproduction or proof of concept, when safe to provide;
- any suggested mitigation; and
- whether cloud credentials or paid provider resources may be exposed.

Remove API keys, account identifiers, SSH keys, callback secrets, and provider
resource identifiers from logs and examples. The maintainers will acknowledge
the report, coordinate a fix and disclosure, and credit the reporter unless
anonymity is requested.
